# Data-Science

** Pandas **
1. Data Manipulation
    DEFINITION :- Changing , organizing or preparing data to make it useful and easier to understand.
    GOAL :- To clean , transform and structure raw data for better usability.
    EXAMPLE :- 
                1. Sorting items into categories.
                2. Correcting missing or wrong grades.


2. Data Analysis 
    DEFINITION :- Extracting patterns , trends , and insights from data to solve real world probleam.
    GOAL :- To answer question or identify trends using the data.
    EXAMPLE :- 
                1. Analyzing sales trends.
                2. Tracking fitness progress.

3. What is Pandas ?
    - Pandas is a powerful and populare python library designed for data manipulation(cleaning, transforming , and structuring data) and data analysis (finding patterns , trends , and insights).
    - It simplifies working with structured dataset like tables , spreadsheets or time-series data.

    * Key Features:
        - Works seamlessly with structured data formats like csv and Excel.
        - Handles missing values easily.
        - Built on NumPy for fast computations.

4. Why Use Pandas ?
    1.Performance : Handles millions of row efficiently.
    2.Ease of Use : Biginner-friendly syntax for cleaning and transforming data.
    3.Integration : Works with libraries like Matplotlib (Visualization) and Sckit-learn. 

5. Series: 
    - A Series is one-dimensional labeled array that can hold any data type: integer, float , string , or even Python objects. Each element in series has a unique label called an index.
    - It often used to track changes or patterns over such as daily temperatures , stock price , or sales revenue.

6. DataFrame:
    - DataFrame is two-dimensional labeled data structure in Pandas, similar to table in a database , an excel , spreadsheet ,or a SQL table.
    - It consists of row and columns. 

7. Data Exploration:
    - Understand the data set.
    - Identify the problem(in dataset)
    - Plan next step.
