5. Key Terms Should Know
    - Data Points : (Single pair of point).
    - X-axis/Y-axis : Horizontal Data/ Vertical Data.
    - Figure : Entire canves(window) where all graps lies.
    - Axes : Graph box (Plotting Area).
    - Plot : Actual data on graph.
    - Marker : Symbol to represent Data Point.
    - Line Style : Connects they Data Points.
    - Color : Color of line , bar or marker.
    - Legend : tells as what each line , point, or graph represents.
    - Label : Use to tell x-axis and y-axis.
    - Title : Use to give title to Graph.
    - Grid : Adds Horizontal and Vertical lines on graph.
    - Function : Performs specifc task (Belong's to object).
    - Method : 
    - Parameters : Information given to function to perform task.
    - Keyword Arguments :used in function , like attributes , work like -> keyword = value , eg :- (color:'Red').
    - Object-Oriented API : Advance way to plot.
    - DPI : Dots Per Inch
    - Backend : not like node or express , it use save and plot the graph.

6. Matplotlib object oriented API
    - The Object-Oriented API in Matplotlib means you work directly with objects such as Figure and Axes, instead of relying on global functions like plt.plot().   
    - Working on big project
    - Controled by you , on which project you want to work.

             plt vs ax

       Pyplot	       Object-Oriented
        plt.plot()	    ax.plot()
        plt.title()	    ax.set_title()
        plt.xlabel()	ax.set_xlabel()
        plt.ylabel()	ax.set_ylabel()
        plt.legend()	ax.legend()
        plt.grid()	    ax.grid()
